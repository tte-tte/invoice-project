# InvoicePro

A small React + TypeScript invoice management application inspired by the provided InvoicePro design.

## Features

- Invoice dashboard
- Search by invoice number or customer
- Filter by status
- Sort by date and amount
- Invoice details
- Create invoice
- Dynamic line items
- Automatic line-item and invoice totals
- Loading state
- Empty state
- Basic validation
- React Router
- Mock invoice service
